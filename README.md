# VidAU for Cursor

Connect Cursor to a VidAU account and generate images and videos.

This repository is the install manifest only. Cursor connects to `https://mcp.vidau.ai/mcp`. Sign in with your VidAU account when Cursor asks. There is no API key in this repository.

## Install

After VidAU is listed, install it from the Cursor Marketplace. Cursor reads `mcp.json` and opens the VidAU sign-in page.

## What you can do

- Check credits and recent usage
- List image and video models
- Quote a generation before spending credits
- Generate an image or video after you accept the quote
- Check task status and history

Reference files must already be a public https address. This plugin does not sell credits or open a checkout.
